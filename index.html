⚙️ First-Time Google Cloud Setup

1

Go to Google Cloud Console

Open console.cloud.google.com and sign in with your company Google account.

2

Create a New Project

Click the project dropdown → New Project → Name it Audit Doc Sender → Click Create.

3

Enable APIs

Go to APIs & Services → Library. Enable both Google Drive API and Gmail API.

4

Configure OAuth Consent Screen

Go to APIs & Services → OAuth consent screen → Choose External → Fill in app name Audit Doc Sender and your email → Save.

5

Create OAuth Credentials

Go to Credentials → Create Credentials → OAuth Client ID → Choose Web application → Add the URL of this app under Authorized JavaScript origins → Create.

6

Paste Your Client ID

7

Register Yourself in Supabase

In your Supabase project, go to Table Editor → app_users and insert a row with your Google email and role admin. This is required to access the app.
